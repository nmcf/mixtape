# AI Context — mixtape

Internal reference for Claude Code sessions. Updated as the project evolves.

## What this project is

Album recommendation engine trained on the MusicBrainz open music database. A user enters an artist name, selects an album, and receives 10 similar album recommendations via a KNN model.

## Tech stack

- **Data store:** MusicBrainz PostgreSQL (source) → Parquet files (working copy) → DuckDB (query layer)
- **ML:** scikit-learn `NearestNeighbors` with cosine distance, sparse scipy matrices
- **App:** Streamlit
- **Environment:** Python 3.11, virtualenv in `env/`

## Notebooks

- Inline developer markdown cells between every code cell explaining the logic of each step

## Pipeline stages (run in order)

### 1-EDA
1. `1-EDA/01-postgres-to-parquet.ipynb` — connects to MusicBrainz Postgres via DuckDB, exports 10 tables to parquet
2. `1-EDA/02-parquet-to-dataframes.ipynb` — joins parquets into 3 pickled DataFrames (album, artist, master)
3. `1-EDA/03-EDA-albums.ipynb` — ydata-profiling report on album features (display only)
4. `1-EDA/04-EDA-artists.ipynb` — ydata-profiling report on artist features (display only)
5. `1-EDA/05-EDA-master.ipynb` — ydata-profiling report on the full joined dataset (display only)

### 2-Prototyping
6. `2-Prototyping/01-feature-tags-labels.ipynb` — builds tag, label, and type sparse matrices; creates master album/artist ID index
7. `2-Prototyping/02-feature-ratings.ipynb` — computes Bayesian-weighted rating vectors aligned to the master index
8. `2-Prototyping/03-feature-assembly.ipynb` — stacks all feature blocks, inspects sparsity, identifies safe pruning threshold (display only)
9. `2-Prototyping/04-knn-training.ipynb` — assembles matrix, prunes columns, L2-normalises, trains KNN, saves model artefacts
10. `2-Prototyping/05-knn-query.ipynb` — interactive prototype for querying the trained model (display only)

### 3-model
11. `3-app/app.py` — Streamlit frontend, loads from `data/model/` and `data/mb_album_artists.parquet`

## Key design decisions

- **Only `release_group` type=1** (albums) are imported — no singles/EPs.
- **Bayesian weighted rating:** `score = (R × v) / (v + C)` with C=5. Collapses to 0 for unrated items. Normalised to [0,1].
- **Column pruning:** columns with fewer non-zero entries than `safe_threshold` are dropped. Threshold is set so no album with features loses all signal.
- **Same-artist exclusion:** recommendations filter out other albums by the same primary artist.
- **Album dropdown filtered** to albums in `album_id_to_row` — albums without features are hidden in the UI.
