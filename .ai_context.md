# AI Context — mixtape

Internal reference for Claude Code sessions. Updated as the project evolves.

## What this project is

Album recommendation engine trained on the MusicBrainz open music database. A user enters an artist name, selects an album, and receives 10 similar album recommendations via a KNN model.

## Tech stack

- **Data store:** MusicBrainz PostgreSQL (source) → Parquet files (working copy) → DuckDB (query layer)
- **ML:** scikit-learn `NearestNeighbors` with cosine distance, sparse scipy matrices
- **App:** Streamlit
- **Environment:** Python 3.11, virtualenv in `env/`

## Pipeline stages (run in order)

1. `datasets/duckdb-parquet.ipynb` — imports 10 Parquet tables from Postgres via DuckDB
2. `datasets/parquet-dataframes.ipynb` — merges Parquet into 3 pickled DataFrames
3. `features/features.ipynb` — builds 4 sparse feature blocks + final stacked matrix
4. `model/knn.ipynb` — trains KNN, saves model artefacts to `data/model/`
5. `app/app.py` — Streamlit frontend, loads from `data/model/` and `data/mb_album_artists.parquet`

## Key data files

| Path | Description |
|------|-------------|
| `data/*.parquet` | Raw MusicBrainz exports (10 tables) |
| `data/pickles/master_df.pkl` | Fully denormalised album+artist DataFrame |
| `data/features/album_ids.pkl` | Row index for all feature matrices |
| `data/features/*.npz` | Sparse feature blocks (tags, labels, types, ratings) |
| `data/model/knn_model.joblib` | Fitted KNN model |
| `data/model/X_knn_norm.npz` | L2-normalised training matrix |
| `data/model/album_ids_annotated.npy` | Album ID index for the training matrix |
| `data/model/has_features.npy` | Boolean mask: which albums have any features |

## Key design decisions

- **Only `release_group` type=1** (albums) are imported — no singles/EPs.
- **Bayesian weighted rating:** `score = (R × v) / (v + C)` with C=5. Collapses to 0 for unrated items. Normalised to [0,1].
- **Column pruning:** columns with fewer non-zero entries than `safe_threshold` are dropped. Threshold is set so no album with features loses all signal.
- **Same-artist exclusion:** recommendations filter out other albums by the same primary artist.
- **Album dropdown filtered** to albums in `album_id_to_row` — albums without features are hidden in the UI.

